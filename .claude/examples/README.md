# Examples

> 使用示例目录

本目录用于存放 Agent Team 和 Workflow 的使用示例，帮助新成员快速上手。

## 示例列表

### Agent 调用示例

```bash
# 架构设计
@architect 设计一个用户积分系统

# API 设计
@api_designer 基于上述架构设计 RESTful API

# 前端实现
@frontend_engineer 实现积分列表页面

# 代码审查
@reviewer 审查积分模块代码
```

### Workflow 触发示例

```bash
# 新功能开发
@feature 实现一个订单管理模块

# Bug 修复
@bugfix 修复订单列表分页异常

# 代码重构
@refactor 重构请求签名逻辑

# 发布流程
@release 发布 v1.1.0 版本
```
