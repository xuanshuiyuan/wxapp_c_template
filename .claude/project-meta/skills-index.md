# Rule-Skills 索引

按需加载，不常驻上下文。**正文里写「见另一个 skill」不会自动加载，需要显式调用。**

| Skill | 主题 | 触发场景 |
|---|---|---|
| `rule-project-structure` | 分层归位 | 新增文件、不确定放哪、评审分层 |
| `rule-add-page` | 新增页面 | 列表 / 表单 / 详情 / 分包页（含骨架） |
| `rule-api-request` | 接口请求 | 加接口、GET/POST/JSON/上传、错误处理、分页契约 |
| `rule-auth-state` | 登录与用户态 | 登录登出、token / 40005、登录拦截、userState |
| `rule-ui-components` | 组件选型 | 选 uview 组件、封装 app-*、easycom |
| `rule-style-css` | 样式 | token / 原子类 / 版式块 / HUD 视觉 / 换肤 |
| `rule-page-services` | 弹窗跳转 | alert/confirm、loading、route 跳转 |
| `rule-multiplatform` | 多端兼容 | 端判定、条件编译、安全区、构建禁忌 |
| `rule-coding-basics` | 编码基础 | 命名、注释、函数规范、魔法值 |
| `rule-testing` | 测试 | 写/评审测试（默认不执行） |
| `rule-security` | 安全 | 敏感信息、XSS、token、鉴权、日志脱敏 |
| `rule-performance` | 性能 | 长列表、请求去重、包体积、重渲染 |

流程类：`project-dev`（需求 → 版本档案 → 实现）、`design-preview`（设计稿 → docs/design HTML 预览）。
