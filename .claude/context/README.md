# Context

> 上下文快照目录

本目录用于存放项目上下文快照、需求文档、设计稿链接、接口文档等临时或长期参考材料。

## 内容类型

- **requirements/**：需求文档
- **designs/**：设计稿或 UI 说明
- **api-docs/**：第三方接口文档
- **snapshots/**：代码上下文快照

## 使用方式

1. 将相关上下文材料放在对应子目录
2. 在对话中引用文件路径
3. Claude Code 会自动读取并纳入上下文

## 注意事项

- 敏感信息不要放入本目录
- 过期上下文应及时清理
- 新增重要上下文在 commit message 第一行说明即可（CHANGELOG 审计已于 2026-11-02 停用）
