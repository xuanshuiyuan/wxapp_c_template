# Docs

> AI 生成的项目文档目录

本目录用于存放 Claude Code 在工作过程中生成的项目文档，如模块设计文档、接口文档、测试报告等。

## 目录结构

```
docs/
├── v1.0.0/              # 按版本号组织
│   ├── frontend/        # 前端页面文档
│   ├── api/             # 接口文档
│   ├── sql/             # 数据库变更
│   ├── tests/           # 测试报告
│   └── requirements/    # 需求文档
└── reference/           # 参考资料
```

## 使用方式

1. 每个版本创建独立的子目录
2. 文档按类型分类存放
3. 文档生成后同步更新 CLAUDE.md 中的「当前开发版本」

## 注意事项

- 文档使用 Markdown 格式
- 每个文档应包含创建时间和版本号
- 重要文档变更在 commit message 第一行说明即可（CHANGELOG 审计已于 2026-11-02 停用）
